# SMIU Events Portal

## 1. Project Overview

The **SMIU Events Portal** is a modern, responsive and mobile-friendly website developed for Sindh Madressatul Islam University (SMIU).

The main purpose of this website is to help students discover university events, explore different societies, view event details and register for upcoming activities.

The website is developed using HTML5, CSS3 and Bootstrap 5.3.3.

## 5. Website Pages

The project contains the following six pages:

1. **Home Page (index.html):** Displays the hero section, featured events, upcoming events and university benefits.
2. **Events Page (events.html):** Displays university events in a responsive card layout with an event schedule table.
3. **Event Details (event-details.html):** Shows complete event information, schedule, speakers, rules and registration modal.
4. **Societies Page (societies.html):** Displays university societies with descriptions and joining options.
5. **Registration Page (register.html):** Provides a student registration form with different input fields.
6. **Contact Page (contact.html):** Contains contact information, contact form, office details, map image and Meet the Team section.

## 6. How to Run the Project

Follow these steps to run the website:

1. Download or clone the GitHub repository.
2. Extract the project folder if downloaded as ZIP.
3. Open the project folder in Visual Studio Code.
4. Open `index.html` in a web browser.
5. Navigate through the website using the navigation bar.

You can also use the Live Server extension in Visual Studio Code for a better development experience.

## 7. Responsive Design

The website is designed to work on different screen sizes:

- Mobile: 360px
- Tablet: 768px
- Desktop: 1200px

Bootstrap's responsive grid system and custom CSS media queries are used to provide a better user experience on different devices.

## 9. Teamwork and GitHub Collaboration

Our team worked together using a shared GitHub repository. Each member worked on a separate feature branch and pushed their changes through Pull Requests.

Team members reviewed each other's code before merging it into the main branch.

During development, we faced a CSS merge conflict because multiple members were working on the shared `style.css` file. We resolved the conflict by reviewing both versions, keeping the required changes from each member and removing duplicate or conflicting code. After resolving the conflict, we tested the website to make sure all pages were working correctly.

This teamwork process helped us understand GitHub collaboration, branching, Pull Requests and code reviews.

## 10. Conclusion

The SMIU Events Portal provides a simple and user-friendly platform for students to explore university events and societies. It allows students to view event information, register for activities and contact the Student Affairs Office.

Through this project, we gained practical experience in front-end web development, responsive design, Bootstrap components and collaborative software development using GitHub.
